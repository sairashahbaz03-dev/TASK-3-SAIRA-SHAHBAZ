# ATM Interface

This project is a simple Java-based ATM Interface developed using Object-Oriented Programming (OOP) concepts.

## Project Description

The ATM Interface allows users to perform basic banking operations through a menu-driven system. Users can deposit money, withdraw money, check their account balance, or exit the ATM.

## Features

- Deposit money
- Withdraw money
- Check account balance
- Validate user input
- Check for sufficient balance before withdrawal
- Display transaction messages
- Exit the ATM system

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Scanner for user input

## OOP Concepts Used

- Classes and Objects
- Encapsulation
- Constructors
- Methods
- Private data members
- Input Validation

## How to Run

1. Clone or download this repository.
2. Open the project in a Java IDE such as IntelliJ IDEA, Eclipse, or NetBeans.
3. Compile the Java file.
4. Run the `atm_interface` class.
5. Follow the ATM menu displayed on the screen.
